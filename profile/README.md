# Lycohinya

[Lycohinya](https://lycohinya.tinyyana.com/) 是 TinyYana 開發、經營的 Minecraft 伺服器，這個組織收納它的核心插件套件與周邊工具。

大部分 repo 是自製 Paper 插件，一插件一 repo：伺服器核心邏輯（花籤、檢定、使魔）、經濟與商城、任務系統、反透視礦物層、大廳與跨服基礎設施等，各自獨立版控、獨立部署。少數 repo（例如 [Lycospec](https://github.com/Lycohinya/Lycospec)）是從內部工具抽出的獨立開源專案，不依賴伺服器本體也能使用。

多數 repo 目前為私有。公開發佈的專案優先採用自製的 TYUSL 1.0 授權。
